# UMMBench
Due to the size limitations of anonymous repositories, we have only uploaded a demo version of the dataset. The full dataset will be open-sourced after the paper is published.
The uploaded dataset includes the following components:
  Textual_200.jsonl contains 200 test samples for large language models.
  vision_100.jsonl contains 100 test samples for Multi-modal models.
  FirstTest.py and SecondTest.py are test scripts for large language models (using GPT-4o-mini as an example).
  FirstTest-mul.py and SecondTest-mul.py are test scripts for multi-modal models (using GPT-4o as an example).
  image_file contains all the images used in the multi-modal problems.
