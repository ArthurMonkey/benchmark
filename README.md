# UMMBench

Due to the size limitations of anonymous repositories, we have only uploaded a demo version of the dataset.  
The full dataset will be open-sourced after the paper is published.

The uploaded dataset includes the following components:

- **Textual_200.jsonl**: Contains 200 test samples for large language models.
- **vision_100.jsonl**: Contains 100 test samples for multi-modal models.
- **FirstTest.py** and **SecondTest.py**: Test scripts for large language models (using GPT-4o-mini as an example).
- **FirstTest-mul.py** and **SecondTest-mul.py**: Test scripts for multi-modal models (using GPT-4o as an example).
- **image_file**: Contains all the images used in the multi-modal problems.
